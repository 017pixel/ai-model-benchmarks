# Deepward

Ein eigenständiges, prozedurales 2D-Sandbox-Abenteuer für den Browser. Die Welt, Spielerposition, Rohstoffe, Bauänderungen und Progression werden automatisch im `localStorage` des Browsers gespeichert.

## Start

```bash
npm install
npm run dev
```

Das Spiel läuft unter `http://localhost:4000`.

## Steuerung

| Aktion | Taste |
| --- | --- |
| Bewegen | `A` / `D` |
| Springen, im Creative fliegen | `W` / `Leertaste` |
| Im Creative abwärts fliegen | `S` |
| Abbauen / Gegner treffen | Linke Maustaste halten |
| Block setzen | Rechte Maustaste |
| Nahkampfangriff | `F` |
| Mit NPC sprechen | `E` |
| Hotbar | `1` bis `9` / Mausrad |
| Survival / Creative | `C` |
| Lokales PvP | `P` |
| Boss rufen | `B` |
| Pause | `Escape` |

Spieler 2 verwendet im lokalen PvP die Pfeiltasten und `Enter` zum Angreifen. Auf kleinen Touch-Geräten erscheinen eigene Bewegungs-, Abbau-, Kampf- und Bauflächen.
